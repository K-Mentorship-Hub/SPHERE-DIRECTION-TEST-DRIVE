# Quest 10 — HardTech & Industry 4.0

**Sphere:** Bridge | **Time:** 2-3 hours | **Difficulty:** Beginner-friendly

---

## Scenario

A manufacturing company wants to modernize one production line with IoT sensors and data collection. You're the project planner — design the pilot project.

---

## Theory Bite

HardTech bridges the **physical and digital worlds**. Industry 4.0 means:

- IoT sensors collect data from physical machines
- Data is analyzed to predict failures, optimize processes, reduce waste
- Automation reduces human error and increases consistency
- The result: less downtime, higher quality, lower cost

Key truth: **the hard part isn't the technology — it's integrating it into existing physical systems where things break, get dirty, and don't have WiFi.**

---

## Hands-On Task

### Part 1: Sensor Selection (30 min)

Choose 5 sensors for a production line that manufactures [pick one: bottles, circuit boards, furniture]. For each:
- What does it measure? (temperature, vibration, humidity, etc.)
- Why does that measurement matter?
- Where would you place it?

### Part 2: Data Flow Diagram (30 min)

Draw the data pipeline:
```
Sensor → Edge Device → Cloud → Dashboard → Alert/Action
```
What happens at each stage? What could go wrong?

### Part 3: ROI Estimate (30 min)

Estimate the business case for the pilot:
- Cost: sensors + installation + cloud + dashboard = $___
- Benefit: reduced downtime by X hours/month × $___/hour = $___/month
- Payback period: ___ months

Use realistic-ish numbers. The point is the thinking, not precision.

### Part 4: Failure Mode Analysis (30 min)

List 5 things that could go wrong with the pilot:
- Sensor breaks in a dirty environment
- WiFi is unreliable on the factory floor
- Workers don't trust the system
- ...

For each, write one mitigation strategy.

- Was the ROI analysis interesting or tedious?
- Do you prefer working with tangible things (hardware) or abstract things (software)?
